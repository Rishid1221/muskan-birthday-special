# Hello Kitty sticker slots

Drop transparent PNG/WebP stickers here using these exact names — each one
is picked up automatically on next reload, no code changes needed. Until a
file exists, that slot shows a hand-coded bow/heart/star placeholder instead.

| filename | currently shown as |
|---|---|
| `bow-1.png` | pink bow (top-left, welcome/cake/etc.) |
| `bow-2.png` | pink bow (lower-left) |
| `heart-1.png` | heart (top-right) |
| `heart-2.png` | heart (bottom-right) |
| `sparkle-1.png` | sparkle (upper-right) |
| `sparkle-2.png` | sparkle (top-center) |
| `star-1.png` | star (bottom-left) |
| `hero-bow.png` | the large centerpiece bow on the Welcome screen |

Square-ish images work best, ~200–400px. They float and gently rotate
automatically — no need to bake motion into the image itself.
